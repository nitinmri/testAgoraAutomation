Question: How do I create a task?
Expected response: Go to Setup > Preventive Maintenance > Tasks, click Add Task from the Task Library, enter the property, create the task name, choose the applicable trade, set the interval, add estimated time and instructions, then click Create or Create and View.
Received response: How to create a task

Tasks are created from the Task Library in Preventive Maintenance.

Go to the Task Library list.
Click Add Task.
In the Add Task window, enter:
Property where the task will take place
Task Name
Trade
Frequency such as Daily, Weekly, Monthly, Quarterly, Semi-Annually, Annually, or More Options for a custom interval
Estimated Time
Instructions
If needed, choose More Options to set a more specific interval, such as 8 months or 4 years.
Click Create to save the task, or Create and View to save it and open the Task Details screen.

If you want, I can also explain how to add task lines or edit a task after it’s created.
